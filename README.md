# Ordum

Aplicativo de finanças pessoais desenvolvido pelo grupo de estudo, com foco inicial em aprendizado e evolução incremental.

## Tecnologias definidas

- Java 21, Spring Boot e Maven no backend.
- Angular no frontend.
- PostgreSQL executado via Docker Compose.
- Backend e frontend executados localmente durante o desenvolvimento.

## Estado do projeto

Este repositório está na etapa de documentação e planejamento. Os recursos descritos são objetivos de implementação, não funcionalidades verificadas. Não há aplicação executável nem comandos de instalação disponíveis neste repositório por enquanto.
